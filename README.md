# Weather Application

A modern and responsive **Weather Application** built with **HTML, CSS, and JavaScript** that provides real-time weather information for any location worldwide.

---

## Project Description

The Weather Application allows users to search for cities and view current weather conditions in real time. It is designed to be simple, fast, and user-friendly while delivering accurate weather data. The project demonstrates core front-end development skills, API integration, and responsive web design.

---

## Features

*  **Location-based weather search**
*  **Real-time weather updates**
*  Displays temperature, humidity, and weather conditions
*  **Fully responsive design** (mobile, tablet, and desktop)
*  Clean and intuitive user interface
*  Basic error handling for invalid locations

---

## Technologies Used

* **HTML5** – Structure and markup
* **CSS3** – Styling and responsive layout
* **JavaScript (ES6+)** – Application logic and API handling
* **Weather API** (e.g., OpenWeatherMap) – Fetching real-time weather data

---

## How It Works

1. The user enters a city name into the search input.
2. JavaScript sends a request to the Weather API using the Fetch API.
3. The API returns real-time weather data in JSON format.
4. The app processes the data and dynamically updates the UI to display the weather information.

---

## Installation & Usage

1. Clone the repository:

   ```bash
   git clone https://github.com/isaacvinny/weather-app.git
   ```
2. Navigate to the project folder:

   ```bash
   cd weather-app
   ```
3. Open the `index.html` file in your browser.

>  No additional setup is required. Ensure you have an active internet connection for API requests.
